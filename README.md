# Доска позора — Telegram-бот

## Что умеет
- Автоматически замечает, когда участник покидает группу или его удаляют.
- Публикует дату, имя/username и заданную шуточную формулировку.
- `/pozor` — последние 10 записей.
- `/stats` — общее число выходов.

## Важно перед запуском
1. Добавьте бота в группу и назначьте администратором.
2. Не отправляйте токен BotFather никому и не вставляйте его в код.
3. На хостинге создайте переменную `BOT_TOKEN` со значением токена.
4. Для сохранения истории между перезапусками подключите постоянный диск/volume
   и задайте `DB_PATH` как путь внутри него, например `/app/data/pozor.sqlite3`.
5. Запускайте только один экземпляр приложения с этим токеном.

## Запуск
```bash
pip install -r requirements.txt
BOT_TOKEN="ваш_токен" python bot.py
```

Telegram требует, чтобы бот был администратором группы и явно запрашивал
обновления `chat_member`. Код делает это через `allowed_updates=Update.ALL_TYPES`.

## Развёртывание в Railway
- Создайте новый сервис из GitHub-репозитория с этими файлами.
- Добавьте переменную `BOT_TOKEN` в Variables.
- Start command: `python bot.py`.
- Добавьте Volume и укажите mount path `/app/data`.
- Оставьте одну реплику/экземпляр.
- Проверьте Deploy Logs: приложение должно запуститься без ошибок.

Тарифы и условия облачного хостинга могут меняться; проверьте цену перед запуском.
